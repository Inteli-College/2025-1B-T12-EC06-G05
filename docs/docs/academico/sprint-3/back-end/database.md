# Banco de Dados

## Introdução

&emsp; Nosso projeto atua no campo da visão computacional, focando na análise de imagens de edificações. Para viabilizar essa proposta, identificamos a necessidade de criar uma infraestrutura robusta de armazenamento capaz de gerenciar todas as imagens que serão utilizadas no treinamento do modelo de inteligência artificial. <br/>
&emsp; A solução inclui o desenvolvimento de uma interface intuitiva que permitirá aos usuários acessar o histórico completo das expedições realizadas pela equipe de campo. Por meio dessa plataforma, será possível visualizar e analisar todas as imagens capturadas das paredes dos edifícios, organizadas de forma clara e acessível. <br/>
&emsp; Considerando que este é um projeto de acesso restrito, também implementaremos uma estrutura de dados segura para armazenar as informações dos usuários autorizados. Para atender a esses requisitos, nossa equipe optou por utilizar um banco de dados relacional como base do sistema. <br/>
&emsp; Esta escolha tecnológica se justifica pela capacidade dos bancos relacionais de organizar informações em tabelas estruturadas, onde cada linha representa um registro único e cada coluna corresponde a um atributo específico. A principal vantagem dessa abordagem está na possibilidade de estabelecer relações entre diferentes tabelas através de chaves primárias e estrangeiras, garantindo eficiência na recuperação de dados e facilitando o acesso a informações interconectadas. <br/>
&emsp; Com essa arquitetura, conseguiremos manipular e apresentar os dados de forma organizada na interface, proporcionando uma experiência fluida e profissional para os usuários do sistema.
