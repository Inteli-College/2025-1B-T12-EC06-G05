# Banco de Dados

## Introdução

&emsp; Nosso projeto envolve o campo de visão computacional, a vista disso. Precisamos de uma estrutrada de armazenamento que consigaos armazenas as imagens que serão utilziafas para treinar o modelo. Além disso, furnecemos ima interfase de interação onde o usuário poderá acessar todas as expedições realiadas pela equipe de campo, obervar todas as imgens caputadas das paredes dos edificios. Além disso, precisamos de uma estrutrada de dadso que consigca armazenas as infromalçoes dos usa´rios jp a que esse projeto é de acesso restrito. Por ocnta disso, nosso gruopo proceguirá o proejto fazendo dados manipulados e apresentados na interfase, em um banco de dados relacional. Um sistema de gestão de base de dados que organiza dados em tabelas com linhas e colunas, onde cada linha representa um registro e cada coluna representa um atributo desse registroOs dados são armazenados em relações, o que significa que as tabelas podem estar relacionadas entre si através de chaves primárias e estrangeiras, facilitando a recuperação e o acesso a informações relacionadas.
