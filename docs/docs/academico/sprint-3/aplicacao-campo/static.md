# static

&emsp;A pasta `static` é utilizada para armazenar arquivos estáticos da aplicação, como imagens e outros recursos que não sofrem alterações dinâmicas.

&emsp;Atualmente, essa pasta contém a logo da aplicação, que é exibida na interface inicial (página de login). A utilização dessa pasta permite manter esses recursos organizados e separados da lógica do código, facilitando a manutenção e a reutilização em diferentes partes do projeto.
