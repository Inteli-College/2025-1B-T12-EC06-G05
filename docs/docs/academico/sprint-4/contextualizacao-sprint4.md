# Contextualização da Sprint 4

&emsp;Após uma sprint marcada por grandes implementações, a Sprint 4 foi voltada ao **refinamento da plataforma**. Nosso foco principal esteve na **melhoria da base construída** até aqui, resolvendo pendências e fortalecendo pontos que precisavam de mais atenção. Esse momento de consolidação foi importante para garantir uma experiência mais fluida para os usuários e garantir que não hajam erros no sistema.

&emsp;Um dos avanços mais relevantes foi a criação de um **novo sistema de logs**, agora também visível no front-end. Isso representou um salto importante para a rastreabilidade e auditoria da plataforma. No banco de dados, realizamos ajustes pontuais que facilitaram essa integração e prepararam o terreno para novas funcionalidades.

&emsp;O front-end evoluiu com a **inclusão de novas telas**, como a tela de perfil do usuário e a tela de visualização de logs. Também introduzimos um recurso que permite visualizar as **imagens de fissuras já cortadas**, com o processamento realizado diretamente pelo back-end. Essa funcionalidade trouxe mais clareza para os usuários na hora de analisar os resultados gerados pelo nosso modelo.

&emsp;Além disso, aprimoramos significativamente o processo de **auditoria**. Adicionamos um sistema intuitivo de **drag and drop** nas imagens, permitindo que os usuários reorganizem e reclassifiquem as imagens diretamente pela interface, tornando o processo mais rápido, direto e acessível.

&emsp;Outro destaque importante foi a **análise financeira**, elaborada com profundidade e embasamento. Ela ajudou a demonstrar a viabilidade e o impacto do projeto, adicionando uma camada estratégica essencial para nossa entrega final.

&emsp;No campo do modelo, decidimos seguir um novo caminho. Percebemos que, apesar dos modelos anteriores apresentarem bons resultados, suas diferenças eram sutis. Por isso, **estruturamos uma pipeline completa para o modelo**, que permitiu um ganho significativo de performance. Essa decisão se mostrou acertada e abre espaço para uma evolução ainda melhor nas próxima sprint.

&emsp;Abaixo estão listadas as principais entregas da Sprint 4 e, na sequência, nosso planejamento interno, simples, mas fundamental para manter nosso foco e organização ao longo dessas semanas.

---

## Principais entregas da Sprint 4

| Área                        | Entrega                                                                 |
|-----------------------------|--------------------------------------------------------------------------|
| Banco de Dados              | Ajustes pontuais e novo sistema de logs                                 |
| Front-end (React)           | Novas telas (perfil, logs) e visualização de imagens cortadas           |
| Interface de Auditoria      | Sistema de drag and drop para reclassificação de imagens                 |
| Logs                        | Integração dos logs ao front-end                                        |
| Análise Financeira          | Estudo completo sobre viabilidade econômica                             |
| Visão Computacional         | Criação de uma pipeline com melhorias significativas na performance      |
