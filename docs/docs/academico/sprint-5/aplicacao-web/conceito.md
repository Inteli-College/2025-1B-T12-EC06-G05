# Aplicação Web

## Conceito

&emsp;A Aplicação Web faz parte do projeto e foi desenvolvida para funcionar como um *hub* central, permitindo o acesso e a análise de todas as expedições já realizadas.

&emsp;Por meio da aplicação, é possível visualizar todas as expedições em um dashboard organizado por prédio. Cada dashboard apresenta dados relevantes, como a quantidade de fissuras encontradas naquela estrutura. Além disso, a aplicação permite auditar as fissuras detectadas: caso alguma tenha sido classificada incorretamente, é possível alterá-la facilmente, apenas arrastando-a para o grupo correto. Também é possível gerar automaticamente um relatório individual de cada prédio, reunindo todas as informações coletadas durante a expedição, como imagens e descrição de cada fissura, além de um relatório geral sobre aquela expedição.

&emsp;Na Aplicação Web utilizamos as seguintes tecnologias:
- **React** (framework front-end)
- **TypeScript (TSX)** (linguagem)
- **Axios** (biblioteca para integração com o back-end por meio de requisições HTTP)
