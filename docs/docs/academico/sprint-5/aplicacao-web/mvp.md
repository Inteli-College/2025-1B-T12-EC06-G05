# MVP Aplicação Web

## Conceito de MVP

O MVP, sigla para _Minimum Viable Product_ ou **Produto Mínimo Viável**, é um conceito amplamente utilizado no desenvolvimento de produtos, especialmente em startups e projetos de inovação. Ele representa a versão mais simples e funcional de um produto que pode ser lançada no mercado com o objetivo de validar uma ideia com o menor esforço e investimento possível.
