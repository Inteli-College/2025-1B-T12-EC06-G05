# User Experience da Aplicação Web

## Wireframe
&emsp;Um wireframe é um diagrama visual que representa a estrutura de uma página web ou de uma tela de aplicativo. Ele é um esboço, um protótipo de baixa fidelidade, que demonstra como os elementos se relacionam entre si e como são estruturados.

&emsp;Diferente da aplicação de campo, que é feito para uso em campo, aplicação web foca na visualização de dados, como imagens, relatórios e estatísticas, e também é possível fazer upload de imagens de fissuras capturas por outros mecanismos além dos drones, permitindo, assim, uma gestão completa e centralizada das operações.
