## Conclusão

O desenvolvimento das plataformas ao longo das sprints permitiu a construção de uma solução funcional, integrada e com potencial de aplicação real. A equipe conseguiu transformar uma ideia inicial em um produto completo, que une tecnologias de visão computacional, sistemas de apoio à decisão e interfaces voltadas ao usuário.

As entregas contemplaram:

- A implementação de uma arquitetura robusta, com back-end, front-end e interface de campo integrados.
- O uso eficiente de ferramentas como Streamlit, React e AWS S3.
- O treinamento e refinamento de modelos de detecção de fissuras, incluindo o uso de YOLO.
- A introdução de funcionalidades como auditoria com drag and drop e geração de imagens processadas.

Além dos avanços técnicos, o projeto também demonstrou viabilidade prática, com uma análise financeira sólida e propostas claras para evolução e escalabilidade.

Com o MVP validado, o sistema está pronto para testes em campo e abre caminho para futuras versões que ampliem sua utilidade e impacto. A equipe demonstrou competência, organização e visão estratégica, entregando uma solução relevante para o setor de inspeções e manutenção predial.
