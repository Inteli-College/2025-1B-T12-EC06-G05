# Sistema Geral

## Conceito

&emsp; Um protótipo de Alta Fidelidade é uma representação interativa e detalhada do produto ou serviço, que se aproxima muito da versão final, tanto em termos de design visual quanto em termos de funcionalidade e interação. ## Conclusão
&emsp; A apresentação do protótipo de alta fidelidade, acompanhada dos user flows por persona, possibilita uma visão clara e detalhada da jornada dos usuários dentro do sistema, alinhada às suas necessidades específicas. Cada fluxo foi elaborado com base em user stories, garantindo que a experiência do usuário esteja no centro do processo de desenvolvimento.
